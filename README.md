# 청자골 아학-교과서 어휘력 카드

초등 3~6학년 교과서 어휘(한자·음훈·뜻·예시)를 학습하고 퀴즈로 확인하는 웹 앱입니다.

| 폴더 | 용도 | 대상 |
|---|---|---|
| `teacher/` | 교사 배포도구: 학교·학년·학급·학기·과목별 출판사를 고르고 **배포** → 학급 링크와 QR 생성 | 교사 |
| `student/` | 학생용 학습 화면 (선생님이 준 링크로만 열림) | 학생 |
| `shared/fonts/` | Noto Sans KR · Noto Serif KR 부분 글꼴 (OFL) | 공용 |
| `shared/img/` | 훈장 캐릭터·기관 로고·앱 아이콘 | 공용 |

## 배포 번호
배포할 때마다 `student-YYMMDD-NN` 형식의 일련번호가 만들어집니다.
링크(`…/student/#c=…&n=student-261020-01`), 표지, QR 파일명, 오프라인용 파일명에 모두 들어갑니다.

## 사용
1. `https://gj-vocab.pages.dev/teacher/` 를 Safari/Chrome으로 엽니다.
2. 학교·학급·학년·학기·과목별 출판사를 고르고 **배포**를 누릅니다.
3. 링크나 QR을 학생에게 알려 줍니다. 학습 기록은 각자 기기에만 저장됩니다.

※ HTML 파일을 아이폰의 파일 앱·메신저 미리보기로 열면 JavaScript가 꺼져 작동하지 않습니다. 항상 웹 주소(https)로 여세요.

## 홈 화면에 추가 (인터넷 없이 사용)
- 아이폰·아이패드: **Safari**로 학급 링크를 열고 → 공유 버튼(⬆) → **홈 화면에 추가**
- 안드로이드: **Chrome**으로 열고 → ⋮ → **홈 화면에 추가(앱 설치)**
- 한 번 열어 두면 서비스 워커(`sw.js`)가 화면·자료·글꼴을 기기에 저장해 이후에는 인터넷이 없어도 열립니다.
- 학급 설정(`#c=…`)은 기기에 기억되어, 주소 없이 홈 화면 아이콘만 눌러도 같은 학급으로 시작합니다.
- 교사 도구(`teacher/`)도 같은 방법으로 설치할 수 있습니다.
- 새 버전을 올리면 다음 실행 때 자동으로 교체됩니다.

## 어휘력편 앱 (app/)
`https://gj-vocab.pages.dev/app/` — 사용자(교사·학생·학부모)·학교·학년·학기·과목별 출판사를 고른 뒤 시작하면 그 범위의 어휘만 표시합니다. 홈 화면 추가와 오프라인 사용을 지원합니다.
